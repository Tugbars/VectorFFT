Using VectorFFT

a cheat sheet: from your data to a transform,
in six steps

The steps at a glance

1  Allocate

Ask vfft_malloc() for the room your values need.
Give it back with vfft_free().

Table 1. How many numbers to allocate for a transform of N points.
TransformInOut
C2C2N2N
R2CNN + 2
C2RN + 2N
/* 8 complex values are 16 doubles */
double *in  = vfft_malloc(2 * N * sizeof(double));
double *out = vfft_malloc(2 * N * sizeof(double));
/* ... */
vfft_free(in);
vfft_free(out);

2  Put your data in order

Sample n goes to position n, and the results come back the same way.
A 2D or 3D array is stored row after row, as in C (2D and 3D).

/* one transform of N points */
cfg.n[0] = N;

/* or a 2D array of 3 rows of 4 */
cfg.rank = 2;  cfg.n[0] = 3;  cfg.n[1] = 4;

Many transforms of the same size go in one call, as a batch,
either one after another or side by side.

/* three transforms, one after another */
cfg.howmany = 3;
cfg.batch   = VFFT_BATCH_CONTIGUOUS;
/* or side by side: VFFT_BATCH_LANE_MAJOR */

3  Choose the precision

FP64 works on double, FP32 on float.
FP32 takes half the memory; FP64 keeps more digits.

/* FP64: double, vfft.h */
vfft_plan p = vfft_create(&cfg);
vfft_execute(p, VFFT_FORWARD, in, out);

/* FP32: float, vfftf.h */
vfftf_plan q = vfftf_create(&cfg);
vfftf_execute(q, VFFT_FORWARD, in32, out32);

The configuration, the flags and vfft_malloc() are the same at both precisions.

4  Choose the layout

Interleaved keeps each real part next to its imaginary part.
Split keeps them in two arrays. Interleaved is the default.

/* one array, the default */
cfg.layout = VFFT_LAYOUT_INTERLEAVED;

/* two arrays */
cfg.layout = VFFT_LAYOUT_SPLIT;

5  Choose the transform

C2C for complex data, R2C for real data, C2R for the way back.
The layout decides which of them you can pick.

Note 1.  Split runs C2C only.

Real data, R2C and C2R, always uses the interleaved layout. R2C writes N/2 + 1 bins: the rest of the spectrum of real data is its mirror image, so it is not stored.

/* complex data */
cfg.transform = VFFT_C2C;

/* real data: R2C, and C2R for the way back */
cfg.transform = VFFT_R2C;
vfft_plan fwd = vfft_create(&cfg);
cfg.transform = VFFT_C2R;
vfft_plan bwd = vfft_create(&cfg);

6  Create, run, destroy

A plan is made once and run as often as you like.
The first time, it measures; after that, it remembers.

vfft_plan p = vfft_create(&cfg);
if (!p) printf("refused: %s\n", vfft_error());

vfft_execute(p, VFFT_FORWARD,  in,  out);
vfft_execute(p, VFFT_BACKWARD, out, in);

vfft_destroy(p);

Note 2.  The backward transform is not scaled.

A forward and a backward run return your data multiplied by N. Divide by N to get the original values back.

To write the result over the input, set cfg.placement = VFFT_PLACEMENT_IN and pass the same buffer twice.

2D and 3D transforms

Give the rank and the size of each axis. The data is stored as a C array:
plane after plane, row after row, the last index fastest.

/* a 3D array: 2 planes of 3 rows of 4 */
cfg.rank = 3;
cfg.n[0] = 2;  cfg.n[1] = 3;  cfg.n[2] = 4;

Real data halves the last axis only:
each row of N reals gives N/2 + 1 bins.

/* real 2D data: 3 rows of 8 in, 3 rows of 5 bins out */
cfg.transform = VFFT_R2C;
cfg.rank = 2;
cfg.n[0] = 3;  cfg.n[1] = 8;

Note 3.  In place, real rows need room for their bins.

Give every row 2 (N/2 + 1) numbers, two more than its N reals when N is even. vfft_info() reports that row length as stride.

A complete program

The six steps in one file: a C2C transform of 1024 points, in FP64.

#include <stdio.h>
#include <vfft.h>

int main(void)
{
    const int N = 1024;

    /* 1  Allocate: N complex values are 2N doubles */
    double *in  = vfft_malloc(2 * N * sizeof(double));
    double *out = vfft_malloc(2 * N * sizeof(double));

    /* 2  Your data, in order: in[2n] and in[2n+1] hold the real and
          imaginary parts of sample x[n] */
    for (int n = 0; n < N; n++) {
        in[2 * n]     = n % 8;
        in[2 * n + 1] = 0.0;
    }

    /* 3-5  Describe it: the vfft_ calls run FP64, and a zeroed
            configuration is interleaved, C2C, out of place */
    vfft_config_t cfg = {0};
    cfg.transform = VFFT_C2C;
    cfg.n[0] = N;

    /* 6  Create, run, destroy */
    vfft_plan p = vfft_create(&cfg);
    if (!p) {
        printf("refused: %s\n", vfft_error());
        return 1;
    }
    vfft_execute(p, VFFT_FORWARD, in, out);
    printf("X[0] = %g %+gi\n", out[0], out[1]);
    vfft_destroy(p);

    vfft_free(in);
    vfft_free(out);
    return 0;
}

It prints:

X[0] = 3584 +0i

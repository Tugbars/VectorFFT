# The refactor-safety baseline

The tools that make a code restructuring provable: capture byte-diffable
artifacts of the library's behaviour before a change, capture them again after,
diff. No timing is ever part of an artifact. Procedure and stop rules:
[docs/design/refactor_safety_harness.md](../../../docs/design/refactor_safety_harness.md);
the reference artifacts and their rules: [reference/README.md](reference/README.md).

```
python src/tools/baseline/capture_baseline.py --out <scratch> [--repeat 3]   # capture the two artifacts
python src/tools/baseline/capture_baseline.py --out src/tools/baseline/reference --repeat 5   # re-stamp the reference
python src/tools/baseline/slice_ladder.py --parent <fn> --helper <fn> ...    # one migration step's ladder of checks
python src/tools/baseline/obj_equiv.py before.o after.o                      # the object-code equivalence proof
python src/tools/baseline/sym_census.py <obj> --defined|--undefined|--mutable
python src/tools/baseline/race_census.py [src/core/vfft.c ...]
python src/tools/baseline/trig_capture.py --out FILE [--repeat 3]
```

## Files

- `capture_baseline.py` -- `golden_bits.txt` (refusal decisions + output-bit digests) and
  `fp_replay.txt`, one process per cell, a fresh seeded store per cell in scratch, LF always,
  repeated so a nondeterministic cell is recorded as such instead of sampled once.
- `harness_golden.c`, `fp_sweep.c`, `trig_digest_probe.c` -- the harness programs; built by
  `gauntlet/build.py` (`--vfft --compile`), binaries land beside them (ignored).
- `slice_ladder.py` -- drives `obj_equiv.py`, `sym_census.py`, `race_census.py` and the
  capture for one migration step.
- `reference/` -- the committed reference artifacts (`*.txt` ride an explicit `.gitignore`
  negation and an `eol=lf` pin in `.gitattributes`; `vfft_baseline.o` is pinned binary).

Moved here from `build_tuned/` on 2026-09-22; every path inside was repointed.

## The layout-separation gate (2026-09-27)

For [docs/roadmap/layout_separation_plan.md](../../../docs/roadmap/layout_separation_plan.md)
(splitting `src/core` into `common/`, `split/`, `il/`), the tools above were made
host-portable and extended into one per-step gate. Nothing here compares a
timing.

```
# once, before the first step: a reference per ISA (kept OUT of the tree, it is host-bound)
python src/tools/baseline/capture_ref.py --isa avx512 --out <scratch>/ref/avx512
python src/tools/baseline/capture_ref.py --isa avx2   --out <scratch>/ref/avx2

# after every step: capture the tree again and compare, rung by rung
python src/tools/baseline/step_gate.py --ref <scratch>/ref/avx512 --isa avx512 [allowances]
```

- `toolchain.py`: gcc/nm/objdump/readelf from env, then PATH, then the old
  mingw152 paths; the exe suffix; the flags key (os, compiler, ISA, CPU model);
  the include set generated by the same recursive walk the builds use; the
  shipped driver flags read from `gauntlet/build.py` itself.
- `capture_ref.py`: every artifact of one capture (list in its docstring):
  the portable `-O2` and the shipped `-O3 -march=native` `vfft.c` objects, the
  preprocessed TU (plain, declaration-sorted, macros), the object's read-only
  strings, the symbol and race censuses, the struct layouts, the codelet and
  binary hashes, the hygiene lists, and the semantic captures below.
- `step_gate.py`: rungs R0 hygiene, R1 bytes, R2 source, R3 strict objects,
  R4 censuses, R5 semantics; what a step may change is stated with explicit
  allowances (`--allow-reorder`, `--allow-changed F,..`, `--rename-map`,
  `--allow-defined`, `--allow-layout`, `--allow-census-move`).
- `obj_equiv.py --strict-data`: keeps immediates and struct offsets, resolves
  every relocation to a named symbol or a constant BY CONTENT, numbers
  branch labels, and compares data objects - the two measured blind spots
  (constants, immediates) closed. Checked: a `0.97 -> 0.96` change fails, a
  function reorder passes, a struct field swap fails.
- `api_sweep.c` + `api_sweep.py`: 271 public-API cells (every transform,
  both layouts, ranks 1-4, every order, in/out of place, batched, threaded,
  owned buffers, the refusal matrix), one process per cell, replayed from a
  sweep store banked once at the reference; a stratified replay of the rows of
  `src/wisdom` itself; the store's load -> save round trip.
- `layout_dump.py`: every struct's size and member offsets, from DWARF.
- `hygiene.py`: duplicate core header names, unresolved includes, and the
  common/split/il dependency rules (active once `src/core/common` exists).
- `elfmini.py`: the ELF reader `--strict-data` needs (no pyelftools).

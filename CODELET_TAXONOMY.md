## 2. BOUNDARY-SPLIT CASCADE — `codelets/zil/avx2/boundary_split/` (39 files; 33 zsplit + 6 zil) [R]

Family contract: **z (packed interleaved) at the buffer boundary, split re/im planes in the scratch interior.** `count % 4 == 0` (4 columns/iteration) — note this differs from pure-IL's `% 2`.

**Stage maps** (bwd runs the fwd order in reverse, terminator kind FIRST):
```
legacy zsplit   : s0s     -> msg ×k -> sterm | sterm2
ZTURN-S (PROD)  : s0t_r4  -> msg ×k -> stf_r4 | stf2_r4 | stfn_r4
DIT-forward     : dts | dtsn | dtso -> msd ×k -> dtt_r4      (bench-only)
```

**Edge vocabulary** (`codelet_zsplit.ml:63-76`) — what a kind actually touches:
- `E_planes(S)` — block-split planes, re at `2*(l*S+k)`, im at `+VW`. Plain vector ld/st, shuffle-free. *(the interior contract)*

### 7a. `codelet_cil.ml` — CANONICAL pure IL (`codelet_cil.ml:1320-1342`)
```
radix{R}_z_ {kind} {b?} {p?} {t?} {g?} {_log3?} _{fwd|bwd}_{isa}
```
| slot | flag | meaning |
|---|---|---|
| `kind` | `--cil-n1` / `--cil-n1t` / `--cil-t2` | `n1` = untwiddled leaf · `n1t` = leaf with corner-turned store · `t2` = twiddled mid |
| `b` | `--cil-blocked [--cil-split m.p]` | 2-pass CT `R = m·p` through a spill array; peak live `R → max(m,p)`. **Non-pow2 REQUIRES an explicit split** — the factorization is a *plan input*, the emitter only validates it. Contract `count % 2 == 0`, no odd tail |
| `p` | `--cil-pretw` (Bwd only) | PRE-twiddle on a backward t2. **RETIRED**, zero files |
| `t` | `--cil-turnst` | corner-turned store — **store FORM decoupled from KIND** |
| `g` | `--cil-turnst-gs` | turned store with **OGs = leg stride**; implies `t`, so the pair always reads `tg` |
| `_log3` | `--cil-log3` | sparse VTW2 sourcing. **T2 ONLY** — refused on n1/n1t (:830-836) |

**`_ct` measured (2026-08-23, front door, clean cells).** The win tracks spill exactly, which is the same law that governs `b`:

| radix | spill % of bulk loop | `_ct` |
|---|---|---|
| 9 | **0.0%** | **0.89–0.94× — LOSES** |
| 15 | 16.5% | 1.32–1.35× |
| 21 | 27.3% | 1.40–1.60× |
| 25 | 37.6% | **2.5×** |
| 27 | 39.3% | **2.2×** |

🔴 **Radix 9 must not be offered `_ct`.** It has zero spill, so factoring buys nothing and the extra pass is pure loss. `C(9)` is still present in both `_CT_FWD_RADICES` lists as of this writing — an open defect, not a decision.

**Order is fixed by the concatenation**: `b` → `p` → `t` → `g` → `_log3`. Hence `n1tb` (kind n1t + blocked), never `n1bt`; `t2b_log3`, never `t2_log3b`. Observable tags: **n1, n1b, n1t, n1tb, t2, t2b, t2t, t2tg, t2_log3, t2b_log3, n1t_ct, t2_ct** (+ the retired `t2p` slot).

KIND = (twiddled ? (post_tw ? "t2d" : "t2") : "n1")
     ^ "c"  const_tw     ^ "b2"/"b" blocked2/blocked   (b needs R>=16; b2 = R64 only)

### 7c. `codelet_zsplit.ml` — CANONICAL cascade (`:565-577`)
```
Printf.sprintf "radix%d_z_%s%s%s_%s_%s" radix k.base r0_tag sink_tag dir isa
```
- `z` = the family marker: **buffer boundary is packed complex z, scratch interior is split planes.** It does **not** mean "emitted by zil".
- `base` comes from a **kind TABLE** (`:169-302`), not letter composition: `ms | msg | msd | s0s | sterm | sterm2 | s0t | stf | stf2 | stfn | dts | dtsn | dtso | dtt`.
- `_r{r0}` appears **iff** base ∈ {s0t, stf, stf2, stfn, dts, dtsn, dtso, dtt} (`:491-494`) because those bake the 4-section geometry into every address. Only `r0=4` is emitted. Legacy kinds must **not** carry it (provenance stability).
- `sk` = `--zp-sink` store-at-def placement; only `E_sect_tap` store edges are sink-capable.

**Stem morphemes** (prefix = cascade stage): `s0…` stage-0 twiddle-free leaf (**fwd = ingest, bwd = finisher — roles INVERT with direction**) · `ms…` mid, split planes both edges · `st…` terminator, carries `TP_PowW1` and does the re-interleave (**fwd = last, bwd = FIRST**) · `dt…` the DIT-forward recombination family.
**Letters inside bases**: `s` split-output DEINT · `t` fused corner-turn/sectioned geometry · `g` group loop in-kernel · `d` DIT placement (`dif=true`) · `z` z-interleaved output · `f` the stf base (chosen so it is *not* `sterm`) · `2` uj2 2-quad · `n` `nat_in` load-side natural addressing · `o` `nat_out` store-side · `erm` "terminator".

🔴 **The CLI kind name is NOT the base.** `s0sb→s0s`, `s0tb→s0t`, `msgb→msg`, `stermb→sterm`, `stfb→stf`, `stfbn→**stfn**`, `msb→ms`. So **`s0sb`, `s0tb`, `msgb`, `stermb`, `stfb`, `stfbn`, `msb` never appear in any filename.** Read the header's `kind=` line (≈line 11), not the name. 14 on-disk bases ↔ 21 accepted kind strings.

**Gates**: radix ∈ {4,8} only · sterm/sterm2/stf2 = R8 only · s0t/dtt = R4 only · `vec_width` **must** be 4 ⇒ **AVX-512 is impossible in this family**.

### 7d. `codelet_oop.ml` — split OOP (`canonical_name`, `:2190-2200`)
```
radix{R}_{TW}_{BUF}_{DIR}_{isa}_{LOAD}_{STORE}[_log3][_twl][_spec…]
```
- `TW`: `n1` none · `t1` **PerGroup** `tw[(j−1)*me+b]` · `t1p` **PerPosition** (broadcast per VW-block) · `t1s` Broadcast — **grammar-legal, never emitted OOP**
- `LOAD`/`STORE`: **`UG`** UnitGroup (group_stride=1, direct loads, no transpose) · **`UL`** UnitLeg (leg_stride=1, AOS→SOA transpose preamble; needs `R % vw == 0` and `me % 4 == 0`, **no remainder tail**) · `SF` StridedFallback — in the type, never emitted.
- **A `UL` edge IS the corner turn, fused into whichever side it sits on**: `UL_UG` = transpose in the t1's LOADS (route **2PA**); `UG_UL` = transpose in the leaf's STORES (route **2PB**). Either gives MKL's two-pass shape with no transpose sweep.
- Appended by gen_main **in this order** (`:1894-1935`): `post_tw` (literal substring **rewrite** `t1_oop → t1_dif_oop`, not a suffix) → `_log3` → `_il_in/_il_out[_sw]` (files deleted) → `_twl` → `_spec` or `_spec{l}_{g}_{ol}_{og}`.
- K=1 monoliths break the pattern: `vfft_k1_mono{N}[_{r1}x{r2}][_il]_{fwd|bwd}_avx2`. `_sw` (implies `il`) = the (im,re)-swapped lattices, which **is** the backward via `IDFT = swap(DFT(swap(·)))` — hence it renders as `il_bwd`.

### 7e. `dft.ml` / `Emit_c` — the split-real mainstream (names built at `gen_main.ml:1487-1639`)
